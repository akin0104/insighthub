# OpsFlow Stage 01 — Process Model

## Problem

Small teams lose momentum when prospect research, ownership, follow-up, and task status live in separate places.

## Personas

- Business development owner: needs a clear next action and follow-up SLA.
- Operations lead: needs aging work, ownership, and exception visibility.
- Manager: needs a reliable view of pipeline movement and conversion.

## Acceptance criteria

- Every open lead has one owner and one next action.
- A stage change can create a dated follow-up task.
- Every automation action creates a timestamped event.
- A user can pause, reassign, or override an automation rule.
